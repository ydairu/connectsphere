It depends on SPM-88 (Preparation). The criteria below are quoted from that row. "SPM-67" in AC3 is now SPM-91/92. ## Other changes made by this increment

- SPM-10's tests and E2E journey now expect the kept-and-marked behaviour; the confirmation dialog's button is **Save significant change**.
- SPM-56's Re-confirm test now sends the technical sign-off back through the Coordinator's choice first. The equipment card explains that the Coordinator sent it back.
- The SPM-88 test that expected 409 for a significant edit in Preparation now expects the return to Planning.

## Known gaps

- **Organiser view.** The Organiser's arrangement summary shows a sent-back sign-off as Awaiting approval but not that it was marked "Changed since approval".
- **Technical rejection after re-approval request.** Technical Support Staff can re-confirm a sent-back Reserved request but cannot reject it; a reserved arrangement that no longer works must be handled outside this flow.
- **Status history display.** The `sign_off_review_decided` and booking re-approval activity entries are recorded but, like other non-field activity, not displayed.
